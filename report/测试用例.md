# 测试用例（按作业模板整理）

本节把 `dataset/tasks/*.json` 中的结构化用例渲染成作业文档「测试用例模板与示例」要求的格式：每个用例给出名称、所属题目、初始状态、输入与步骤、预期输出、覆盖内容、实际输出及结果，且**每一步都写明检查内容**。

| 覆盖范围 | 数量 |
|---|---|
| 题目 | 30（公共题 20 + 自建题 10） |
| 测试用例 | 54 组 |
| 扫描步（测试步） | 199 个 |

**执行与判定语义**

- 每个用例使用独立的被测功能块实例（内部状态从零开始），按下表顺序「设输入 → 执行一个扫描周期 → 断言输出」。
- 「周期」列为扫描步序号（从 0 开始）；标注「连续 N 拍」的步表示输入保持 N 个周期，在第 N 个周期结束后断言一次，用于让定时器/状态机推进。
- **只比较「预期输出」列列出的输出/元素**，未列出的输出不做检查；空表项记作「本步不检查输出」。
- 「实际输出」列由**参考实现在 CODESYS 仿真中逐拍实测**得到（`dataset/render_cases.py` 生成，缓存于 `dataset/.cache/`）。BOOLEAN 显示为 1/0，`T#` 为时间字面量。
- 模型生成代码的逐题判定结果（编译/测试通过率）见 `experiments/results.csv` 与实验报告第 5 章；自动测试会把同一套用例编译成 ST 自测驱动在 PLC 内执行，因此各框架、各模型使用完全相同的用例与判定标准。
